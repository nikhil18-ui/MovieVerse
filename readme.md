
# 🎬 MOVIEVERSE - Movie Explorer

Welcome to **MOVIEVERSE**, a movie discovery website created by Nikhil Kumar.

This is a beginner-friendly web development project created as part of my learning journey as a BCA student.

Explore movies, check ratings, discover movie rankings and save your favourite films!

## 🌟 Features

- Browse 15 manually added movies.
- Search movies by name.
- Filter movies by genre.
- Sort movies by highest rating.
- Find the top 3 highest-rated movies.
- Find the top 3 longest movies.
- Find the top 3 shortest movies.
- View movie details.
- Add and remove favourite movies.
- Save favourites using LocalStorage.
- Responsive design for mobile and desktop.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
4. Start exploring movies!

No API key or backend is required.
